# c02 — (3,14): metacyclic sweep, larger orders
Goal: first value at (3,14). Size law at mu 5: 2N ~ 5,200; exhaustive searches beat that by 35-60 % at D = 11/12, so aim
for N = 3,500 .. 4,500 (graphs 7,000-9,000). Card c01 does (3,13) with the same tool (N <= 3,600); you must beat whatever
(3,13) value exists (at least 2,176), and ideally reach 7,000+.
Tool: $B/bin/exh3 (see c01.md for the table format and the metacyclic multiplication). At N ~ 4,000 full exhaustive pairs
are slow: write a variant exh3s.c that samples y at random (or restricts x to a few class representatives) and stops at
the first cost-0 pair; time it per group and keep each run under 100 s.
Sweep N from 4,600 down; groups Z_m x|_r Z_k, all k with a valid r. Check every find with $B/bin/apsp (diameter <= 14).
Score: vertices of the largest apsp-checked graph with diameter <= 14.
