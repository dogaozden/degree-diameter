# c05 — Δ = 4 exhaustive orbit scan (new tool): (4,13) and (4,14)
Idea: with ORBIT "3 1 1", S = {e, x, a(x), a^2(x)} depends on ONE element x, so the whole search space is ~N/3 orbits.
At N ~ 1e5 one BFS costs ~1 ms, so an exhaustive scan of all x takes ~1-2 min per group: exhaustive beats annealing
and can reach larger mu than haar_big0's annealing.
Write orbscan.c: G = SL(2,p) x Z_n (and PSL), alpha = conjugation by g = [[0,-1],[1,-1]] (order 3 in PSL; check it) times
z -> r z (r of order 3 mod n, n prime = 1 mod 3, or n = 1). For each alpha-orbit {x, ax, a^2x} with x not alpha-fixed:
BFS on H(G,S) from (e,A) and (e,B) to depth D (vertices (g,A) ~ (s g, B)), cost = A-side + B-side elements not reached
within D-1 from the same-side start (odd D) / B-side not within D-1 of (e,A) (even D; see haar_big0.c header for the
exact definition). Early-abort when cost > current best. Validate on the known (4,14) solution
research/frontier/beyond13/sols/d4D14_sl_31_7_orb3-1-1_s1.txt (cost 0 at D = 14, cost > 0 at D = 13 expected) and against
haar_big0 EVAL on 2 other S. Then scan groups from pick.py (mu 2..15) at (4,13) and (4,14), largest N first within your
time, report every cost-0 x, write a solution file (haar_gen3 format: header line "4 D sl p n NCYC N" ... copy the format
from the (4,14) solution file) and check it with haarcheck_gen.
