# f16 — wildcard: non-abelian voltage lifts at Δ = 3
Cyclic (Z_n) lifts of GP(10,3) won (3,13) 3,200 and (3,14) 5,600. Abelian voltage groups grow polynomially (degree = Betti
number of the base); a non-abelian voltage group (Z_m x|_r Z_k, SL(2,p), A_n) has more distinct voltage words, so the same
base may carry a larger lift. Write a lift annealer with voltages in a metacyclic group Z_m x|_r Z_k (or another small
non-abelian group): vertex (v, g), edge (u,g) ~ (w, g * volt(u,w)). The lift is not vertex-transitive in general — BFS from
one vertex per base vertex is enough only if the voltage group acts by automorphisms (left multiplication does: (v,g) ->
(v, h g)), so use that. Targets: (3,13) beat 3,200; (3,14) beat 5,600. Check with apsp. Score: largest VALID graph.
