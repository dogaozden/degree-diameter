# f03 — theory: why cyclic lifts beat Haar graphs at Δ = 3, and how far they go
Facts: at Δ = 3 the best graphs are Z_n lifts of small cubic bases (Desargues GP(10,3): 3,200 at D = 13, 5,600 at
D = 14), above Haar graphs of any group tried (2,880 A6 x Z4; 5,040 PSL(2,7) x Z15). In an abelian voltage lift the end of a
walk is determined by the base walk's end and the voltage sum, and the voltage sum depends only on how many times each
base edge is used (a vector in Z^E), modulo the cycle space: so the number of distinct (endpoint, voltage) pairs within
distance L grows like a polynomial of degree beta = E - V + 1 (Betti number) in L.
Tasks: (1) count, for GP(10,3) (beta = 11), the number of distinct voltage sums of nonbacktracking closed/open walks of
length <= 12, 13 exactly (or estimate) as a function of n, and predict the largest n with diameter <= 13, 14; compare with
the found n = 160 (D = 13) and n = 280 (D = 14). (2) Which base maximises n * b at fixed D: trade-off between b and beta.
(3) Extend the prediction to Δ = 4 lifts (beta = 2b/2... = b + 1 for 4-regular bases with b vertices) — is n * b ~ 190,000
at D = 13 plausible? Write research/squads/beyond13/r3/f03/LIFTS.md (short, with numbers). Score 0; rule in "next".
