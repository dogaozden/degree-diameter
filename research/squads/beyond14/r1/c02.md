Bases to build (python, no networkx installed; write LCF expansion yourself; make the base bipartite and relabel so
sides are A = [0,h), B = [h,2h); file format: first line b, then "u v" per edge): Tutte 12-cage (126 vertices, LCF

n = 191..195. Verify girth and bipartiteness of each base first.

research/frontier/beyond14/bin/scan_h02 BASE n 14 95 SEED OUT2 6`. Compare start/after-anneal costs between bases at equal b n first (one
