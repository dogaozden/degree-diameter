# c04 (3,14) wildcard: cubic bipartite Cayley graphs / groups of order 2,856-3,300
Goal: a cubic bipartite vertex-transitive graph of diameter 14 with more than 5,706 vertices that is not a cyclic lift.
Route A: Haar graphs H(G,{e,x,y}) of groups G with 2,856 <= |G| <= 3,300 OTHER than metacyclic-with-small-k and
PSL(2,7) x Z15 (already tried): e.g. SL(2,q) x Z_n, PGL(2,q) x Z_n, AGL(1,q) x Z_n, Z_m x|_r Z_k with k >= 9, products
of two metacyclic groups, A5 x Z_n, S4 x Z_n, Z_p^2 x| Z_k. For each group, search pairs (x,y) (exhaustive over x up to
automorphism-ish symmetry is too big; sample many random pairs fast with a C BFS: |G| <= 3,300 so a full BFS is ~10 us).
Route B: Cayley graphs Cay(G,{a,b,c}) with a,b,c involutions outside an index-2 subgroup (bipartite), |G| > 5,706:
generated by three involutions, e.g. subgroups/quotients of Coxeter groups, PGL(2,q) (q = 19: 6,840; check
bipartiteness: the involutions must lie outside PSL(2,q)), dihedral-type extensions Z_m x| Z_2 x ...; BFS from e only.
Write one C program with a generic multiplication table (|G| <= 7,000). Report the best VALID graph above or below
5,706 and the group families' best costs at the record size.
