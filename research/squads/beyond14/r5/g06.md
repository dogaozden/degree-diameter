# g06 (3,14): a hole-directed finisher for lifts (port of r4/f09's idea to salift states)
Goal: a VALID cubic lift with more than 7,004 vertices. States: research/squads/beyond14/r3/e02/Z37N_c1.best (Z37 x|_8 Z48, order 1,776,
7,104 vertices, cost 2; strict local minimum for single moves per r4/f01), research/squads/beyond14/r3/e02/Z17N_c1.best (Z17 x|_2 Z104,
1,768, cost 2), research/squads/beyond14/r3/e04/psl7_11_s5.sol.best (PSL(2,7) x Z11, 1,848, cost 4; tables via r3/e04/mkg.py).
Write the finisher (copy research/frontier/beyond14/ownsmall/salift_s.c): list the uncovered (root, vertex) pairs; for a random one (u, (v,g)), pick a
random walk of length <= 14 in the base from u to v that uses base edge e, and set e's voltage to the unique value that
makes the lifted walk end at g; evaluate (exact cost), keep the best of K such candidates (sideways allowed). Also try
pairs of voltage changes on the edges of that walk. Cost 0: build_lift_tab.py + apsp. Folder: research/squads/beyond14/r5/g06/.
