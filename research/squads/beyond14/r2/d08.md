# d08 (4,14): regular lifts of small 4-regular bases over metacyclic groups (new tool)
Goal: a VALID 4-regular bipartite graph of diameter 14 with more than 498,798 vertices, built as a regular voltage lift
of a p+p base (p = 2 or 4) over a metacyclic group G = Z_m x|_r Z_k of order |G| = n/(2p) (p = 2: |G| >= 124,700;
p = 4: |G| >= 62,350). At Δ = 3 this beat every Haar graph by 25 % (6,328 vs 5,040): a Haar graph is the p = 1 case
(the dipole), and a small base adds freedom. Nobody has tried it at Δ = 4.
Tool to write (copy research/frontier/beyond14/ownsmall/salift_s.c into your folder and change it): degree 4 (the
base = 4 perfect matchings between whites 0..p-1 and blacks p..2p-1, each edge with a voltage; parallel base edges
need different voltages), group multiplication BY FORMULA instead of a table: element (x,j) <-> index x*k + j,
(x,j)(y,l) = (x + r^j y mod m, j + l mod k) (precompute r^j). Lift: (u,g) ~ (v, g*a) for base edge (u,v,a).
Cost exactly as salift: BFS from the 2p roots (u, e) at once with a 64-bit mask per vertex, D = 14 steps, count
(root, vertex) pairs not reached (vertex-transitivity under left multiplication makes this exact).
At n ~ 500K one evaluation is ~20-50 ms. Moves: change one voltage to a random element (50 %), swap the black ends of
two base edges (50 %); Metropolis with T from ~10 down to ~0.3, restart from the best after many idle moves; START from
a .best file. Test the tool first on a tiny case against research/frontier/beyond14/bin/apsp (build the edge list).
Groups: Frobenius m prime, k | m-1, k >= 7, m k = |G|; start at n ~ 480K-500K to calibrate, then above 498,798.
Check: edge list + `research/frontier/beyond14/bin/apsp EDGES 4 14` (500K vertices: ~1-2 min; run it with timeout 105,
if it times out report the file and the director checks). Folder: research/squads/beyond14/r2/d08/.
