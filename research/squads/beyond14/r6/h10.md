# h10 (3,14): exhaustive cubic Haar graphs (p = 1) over Frobenius groups of order 3,504-3,700
Goal: a VALID cubic Haar graph H(G,{e,x,y}) with more than 7,004 vertices, or a clean negative. For a Frobenius group
Z_m x| Z_k almost all of Aut(G) (order ~m(m-1)) acts on pairs (x,y), so only ~k^2 classes need testing: fix x in a set of
class representatives (e.g. x = (1, j) for j in Z_k, and x = (0, j)), let y run over the whole group, evaluate each H with a
fast BFS (|G| ~ 3,600: microseconds). Groups: every Frobenius Z_m x| Z_k (m prime, k | m-1, k >= 5) with order 3,504-3,700.
Report the best cost per group (and any cost-0 graph: write its edge list, check with apsp EDGES 3 14).
