# c2: (1,2)-swap local search (maximum independent set style) for the q=11 packing
Goal as c1 (scorer: CHECKONLY=1 ./pack ../data/gh_11.txt 0 1 /dev/null FLAGS). Write a C program (start from pack.c's
zone functions) doing Andrade-Resende-Werneck style iterated local search: a (1,2)-swap removes one flag and inserts
two flags whose zones are free; perturb by forcing in a random flag and removing the flags it overlaps. Run <= 600 s per
run via heavy.sh. Report the best VALID N and the flags file.
