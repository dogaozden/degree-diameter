# c8: super-hubs on the (14,7) graph
Goal: add vertices beyond the units. A super-hub is a new vertex joined only to hubs (uhcheck EXTRAS format: first line
NS, then edges "a b" between new vertices; hubs are 0..2NU-1, line-side hub of unit i = 2i, point-side = 2i+1, super-hubs
2NU..). A point-like super-hub w joined to line-side hubs z_i reaches (p_i, c) in 2 steps for every copy c, so it needs
the freed points' 4-balls (in H(q) plus the matching edges, any copy shift) to cover all points, and similarly for the
other new vertices. Build on cells2-style files from `QUICK=1 ./t2cell.sh c8_base ../data/gh_11.txt 2 14 1 1`
(hub graph degree 9; you may rebuild it with lower degree via randhub.py to free slots). Check with
`ONLYUNITS=1 ./uhcheck ../data/gh_11.txt STATE UNITS EXTRAS 7 1` (it checks all new vertices). Start at q = 5
(`./t2cell.sh c8_q5 ../data/gh_5.txt 2 8 1 1`, Delta 8) where checks are instant. Score: super-hubs added, valid.
