# c5: groups with unipotent elements (order 11) and Borel-type groups
Order-11 elements (unipotent: (u - 1)^7 = 0) give very different orbits than tori. The cell-13-7 session found a
397-point set from orbits of an order-11 "Eichler transformation" and the cyclic unipotent groups alone give little.
Build unipotent elements explicitly: Siegel/Eichler transformations E(u, v): x -> x + B(x,u) v - B(x,v) u - Q(v) B(x,u) u
(u singular, v orthogonal to u) are isometries; root subgroups; regular unipotents (products of root elements of
different roots). Combine them with small torus elements normalising them (Frobenius groups 11:5, 11:10, 11:2,
11^2:5, Heisenberg-type groups of order 121 or 1331 inside a unipotent radical, 11:10 x 5 ...). Use ovlib for matrix
algebra (check every generator with ovlib.is_isometry(M, ovlib.std_gram(11), 11)). Run orbclq on many such groups of
orders 22..1500; report the best invariant set.
