# c8: WILDCARD B - Frobenius-type groups from the non-split tori
The cyclic tori of types E6 (order q^3+1 = 1332 on an elliptic 6-space = F_{11^6}), H6 (q^3-1 = 1330), E4 (q^2+1 = 122
on F_{11^4}) and H4 (q^2-1 = 120) are normalised by the field automorphism (Frobenius x -> x^11 on the field model,
order 6, 3, 4, 2 resp.), giving metacyclic groups such as 37:3, 37:6, 111:3, 19:3, 19:6, 7:3, 7:6, 133:3, 61:4, 61:2,
15:2, 5:4 ... ovlib builds the tori in field coordinates (see ovlib.block: 'E6' is F_{q^6} with Q = Tr(N(x)), etc.);
build the Frobenius map in the same basis (x -> x^q is F_q-linear: its matrix columns are the images of t^j), check it
preserves the block form (it does for these forms), embed on the block + identity or -1 on the rest, conjugate with the
P returned by ovlib.torus (P maps block coordinates to standard ones: M_std = P M P^-1), and run orbclq on the
metacyclic groups and their products with elements on the complementary block. Report the best invariant set.
