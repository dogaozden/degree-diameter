# f04 — Δ = 4 symmetric lifts: quartic bases with a large rotation (liftsym supports degree <= 8)
New idea: the symmetric-lift family (liftsym) worked at Δ = 3. Try it at Δ = 4 on quartic bipartite bases with a big
automorphism: e.g. the incidence graph of GQ(3,3) = W(3) (80 vertices, girth 8), of PG(2,3) (26 vertices, girth 6,
Singer rotation of order 13 — this one only reproduces metacyclic Haar graphs), or circulant-like bipartite quartic graphs
Haar(Z_k, {0,a,b,c}) with rotation (2 vertex orbits) and their bigger relatives with several orbits. Write the base in
lift format (sides 0..h-1 / h..2h-1), its automorphism as a .perm, run liftsym anneal at (4,15) or (4,16) sizes
(b*n ~ 1.35e6 or 3.5e6). Check finds with apsp if < 5e5 vertices, else report the .best for the director. Score: VALID or best_cost.
