# c5-selfdual (handsoff-108): twisted pairing S^-1 = beta(S) with an order-3 alpha

Card: research/squads/handsoff-108/cards.md, section c5-selfdual. Seeds used: 108901-108971 (all inside 108901-108999).
Status: finished, negative. No member reached cost 0 or anything near it. Processes stopped.

## Result

The twisted family S = {e} + O + iota(O) + F3 (iota(x) = beta(x)^-1; O an alpha-orbit of size 3; F3 an alpha-orbit
of iota-fixed elements) is worse than the standard k=3 family in every valid group I could build. Raw uncovered
counts, D=8, plain (not ORBW-weighted), 3000 random members per row:

| group (N) | family | min | p1 | p10 | median |
|---|---|---|---|---|---|
| psl 23 x Z97 (588,984) | standard | 24 | 56 | 84 | 141 |
| psl 23 x Z97 (588,984) | twisted, inner beta (VERIFY OK) | 125,257 | 127,458 | 130,129 | 141,318 |
| prod psl 5 x psl 27 (589,680) | standard | 47 | 64 | 94 | 180 |
| prod psl 5 x psl 27 (589,680) | twisted, beta inverts alpha on both factors, beta2 minimises iota-fixed set (VERIFY OK) | 113 | 171 | 277 | 1,226 |
| prod psl 5 x psl 27 (589,680) | twisted, beta2 = identity (VERIFY OK) | 214 | 340 | 599 | 4,121 |

(Earlier 300-sample runs: psl 23 standard min 40, median 152; the card quotes min 36, median 135.)

Family size on psl 23 x Z97: 98,120 pair-orbits {O, iota O} x 84 iota-fixed alpha-orbits = 8.24e6 members. A random
sub-sample of 252,000 of them (3000 pairs x 84, ENUM=1 ENUMMAX=3000 THR=200, enum_psl2397_sub3000.out): none below
cost 200 (251,905 aborted at >= 200). Full enumeration would take about 2.4 h of one core at 1000 members/s, and
the sample says the cost is about 125k, so I did not run it. The prod family (about 1.4e8 members) is also too big.

## What is possible (algebra, checked numerically)

- S^-1 = beta(S) <=> iota(S) = S with iota(x) = beta(x)^-1, an anti-automorphism with iota^2 = 1. Odd alternating words
  go to odd alternating words, so the covered and uncovered sets are iota-invariant. VERIFY=1 checks: S closed under
  alpha and iota; iota(xy) = iota(y)iota(x); iota^2 = 1; uncovered set invariant under iota and alpha (0 violations).
- iota must normalise <alpha>. Two cases:
  - alpha commutes with beta on every factor: needs beta to commute with alpha on each factor.
  - alpha is inverted by beta on every factor (beta alpha beta^-1 = alpha^-1): the card's "beta inverts a".
- psl q x Z_n with alpha = (conj a) x (z -> r z), r of order 3: Aut = PGL(2,q) x Z_n^*, and every automorphism of Z_n
  commutes with r, so beta must commute with a. The card's "outer involution inverting a" is therefore impossible.
  Checked over GL(2,23): the involutions of PGL(2,23) commuting projectively with a = mat(1,3,15,0) are all inner
  (22 matrices, det 3, a square mod 23). So beta = conj(mat(1,6,7,22)), iota_Z = inversion (forced, else the iota-fixed
  set has 24,638 elements).
- prod PSL(2,5) x PSL(2,27): alpha on PSL(2,27) must be unipotent (3 = p). A commuting involution does not exist in
  PGL(2,27) (centraliser of a unipotent is elementary abelian), so beta2 must invert alpha2. Both-factor inversion is
  possible (beta1 = conj of an involution inverting a1 in PGL(2,5); beta2 = conj of [[-1,x],[0,1]]).
  A beta2 that commutes with alpha2 (or does not normalise <alpha>) makes S leave the family: VERIFY fails
  (iota-violations about 6,500). Those runs are not valid data and are not in the table.

## Why the Poisson count fails

Standard model: P(x uncovered) ~ e^-lambda, lambda = W/N = 5,380,840/N ~ 9.1, mu = N e^-lambda ~ 63.5. Under the
symmetry Z6 or S3 generated by alpha and iota the expected uncovered orbit-units drop to mu/6 ~ 10.6, so
P(cover) ~ e^-10.6 per member, i.e. about 200 solutions in the 8.2e6 psl family. The data do not show that gain.

Distinct elements of odd non-backtracking words (direct enumeration; psl 23 twisted member, seed 108901):

| word length | words | distinct, twisted | distinct, standard |
|---|---|---|---|
| 1 | 10 | 10 | 10 |
| 3 | 810 | 700 | 801 |
| 5 | 65,610 | 40,833 | 60,890 |
| 7 | 5,314,410 | 424,415 | 588,870 |

The BFS cost of that member is 164,569 uncovered = 588,984 - 424,415, so the BFS and direct word count agree.

Mechanisms found:
1. psl x Z_n: one free Z-parameter. The orbit O carries z, iota(O) carries -z, F3 carries 0, so each word's Z-part is
   c(w) z with c(w) a short signed sum of powers of r. Each Q-fibre sees only about 70-85 % of its 97 Z-values.
   A standard member has three free z's. (Verified: VERIFYGEN=1 fibre histogram; the subgroup <S> is all of G.)
2. Involution letters (prod with beta2 = identity): iota acts as plain inversion on the second factor, so the
   iota-fixed letters have involution second components. Then (x, e, y) = (x, y, e) for every x whenever y is an
   involution: an e-collapse. The fix is beta2 nontrivial (BETA2SEARCH), which drops the median from 4,121 to 1,226
   (inverting case). This is the same mechanism as card section 8.4, where PSL(2,7) x SL(2,8) gave median 1050.
3. Size of the iota-fixed set F: in the prod group F = F1 x F2 with |F2| >= 378 for any involutory beta2 (|F| = 3,779).
   Measured: 184 of 3,779 iota-fixed elements uncovered in one member (about 5 %), against the e^(-lambda/2) ~ 1 %
   model. Each F-orbit uncovered costs 3 elements, so the F term alone is about 13 orbit-units.
4. Relations x iota(x) (always iota-fixed) equal to letters of F3: about 1 member in 84 (not typical).

Variants tested and dead:
- FIXI=1: alpha- and iota-fixed letter u = t instead of e. Then iota(x) = u x^-1 u for all x and words collapse
  identically: RANDORB min 156,236, median 172,014 (200 samples).
- ALPHA1ONLY=1 (alpha trivial on the second factor), standard and twisted: median 461,863 / 474,045. Dead before any
  iota question: a factor on which alpha is trivial makes every orbit's component there constant.
- Commuting beta2 on PSL(2,27): does not exist (see above).

## Tools (this folder)

- haar_c5.c = research/d10D8/sym2/haar_sym2.c plus:
  - INVPAIR=2 for plain PSL(2,q) x Z_n (inner or outer beta commuting with alpha; scalar M excluded);
  - INVERTING=1: beta inverts alpha on each factor (prod groups); BETA2SEARCH=1: beta2 on the second prod factor, chosen
    among B2TRIES random involutions (default 300) to minimise iota-fixed elements, involutions first;
  - ALPHA1ONLY=1: alpha = conj by (a1, e) on a prod group;
  - VERIFY=1 (symmetry checks; use FAST=1), VERIFYN, VERIFYGEN=1 (subgroup and Z-fibre coverage), VERIFYCOLL=1
    (distinct words per length), VERIFYCOLL3=1 (length-3 collision list), CHKINV=1 (involution pattern of letters);
  - FIXI=1 (fixed letter = first alpha-fixed iota-fixed element);
  - ENUM=1 exhaustive family enumeration with THR (bound, default 40) and ENUMMAX (random pair sub-sample); CAND lines
    for cost <= 9; check_and_write on cost 0.
- Build: gcc -O3 -march=native -fopenmp -o haar_c5 haar_c5.c -lm
- Speed on this loaded machine: RANDORB about 100/s with FAST=1, about 600/s with the default wide rows; ENUM about
  1,000/s (bounded).
- Known cosmetic bug: setup_beta prints "det ..., non-square" also when the det is a square. mat(1,6,7,22) has det 3,
  a square mod 23.
