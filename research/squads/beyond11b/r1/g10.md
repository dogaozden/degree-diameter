# g10: a deterministic cover of -I at odd D (cells (6,11), (9,11), (12,11)-like)
-I in SL(2,p) is a central, alpha-fixed involution: at D = 11 (h = 5) a random S misses it with probability up to ~0.5,
on both sides at once, and it is the last hole of many near misses. Lemma to use: if a, b in S and x = a^-1 b has
x^h = -I (x of order 2h = 10 in SL(2,p), i.e. projective order 5, exists iff p = +-1 mod 5), then the word
a^-1 b a^-1 b ... (2h letters) = -I covers -I from (e,A), and (a b^-1)^h = a x^h a^-1 = -I covers it from (e,B).
(The earlier "x with x^2 = -I as a fixed generator" card was weak; this is different: it constrains a PAIR inside S
and keeps alpha-orbit symmetry, e.g. a = t, b = alpha(t) in the same orbit with z(t) = 0, or a = e, b in an orbit.)
Implement: copy haar_big0.c, add an option that constrains orbit slot 0 to satisfy the condition (resample candidates
for that slot until it holds), and compare against plain haar_big0 at equal budget: RANDORB-style start costs and
solve rates on (6,11) "3 2 0" or (9,11) "3 3 0" with SL(2,p) x Z_n, p = +-1 mod 5, at mu 10-16 (above the values;
pick.py). Beat 2,094,960 / 155,250,816 if you can; a solve-rate comparison is the main output.
