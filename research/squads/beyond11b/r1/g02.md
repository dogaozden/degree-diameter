# g02: (4,11) with ODD-ORDER groups (beat 24,360)
Idea: at odd D, involutions and central elements are the hard holes; an odd-order group with trivial centre has
neither. The (3,11) value is odd-order metacyclic. Untested at Δ = 4 (round r1/c13 of an earlier job annealed metacyclic
groups of ANY order k and got 17,600; nobody restricted to odd order with large odd k).
Groups: Z_m x|_r Z_k with m prime (or composite), k ODD (k = 9..99) dividing the order of r mod m, order N = m k in
12,181-20,000 (2N > 24,360); Frobenius-type has trivial centre when r has order exactly k mod m with no fixed points.
Search: `ORBIT` is optional; start with plain random S: `THREADS=1 timeout 105 nice -n 10 $B/haar_gen3 4 11 100 <seed> 4
OUT meta m k r 1`, then haar_sym with ORBIT="3 1 1" if an automorphism of order 3 exists (ALPHA/AR options, read
haar_sym.c). Go up in N from 12,181; for each group 2-3 seeds of 100 s. Use mu = N exp(-W/N), W(4,11) = 88,573, to
predict where random S should stop (mu ~ 5 at N ~ 11,450); you need groups that beat the size law.
Scorer: build_haar2.py on the solution file. Cap 180 MB. Folder: research/squads/beyond11b/r1/g02/.
