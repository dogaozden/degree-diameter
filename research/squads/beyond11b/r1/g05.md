# g05: odd D with a FROBENIUS automorphism: SL(2,p^e) x Z_n, alpha = (x -> x^p) x (z -> r z) (cells (5..11, 11))
Idea: the current alpha (conjugation by a matrix of order 3) fixes a torus of ~p elements, and alpha-fixed elements are
clumped holes at odd D (~p exp(-lambda/3)). The field automorphism x -> x^p of GF(p^e) (order e) fixes only the
subgroup SL(2,p) x {0} (p^3 - p elements, tiny for p = 2, 3, 5, 7). haar_sym supports it: AFROB=1 with `sl q`
(q = p^e, e = 3 gives orbits of size 3: ORBIT "3 m f"; e = 5 gives size 5). Avoid p = 2 (char 2: ~q^2 involutions).
Groups: SL(2,27) = 19,656, SL(2,125) = 1,953,000, SL(2,343) = 40,353,264, SL(2,243) (e = 5) = 14,348,664, times Z_n
with r of order e mod n (n = 1 allowed). Find which (q, n, Δ) land near mu 5-12 for a D = 11 cell with Δ <= 11 (compute
mu = N exp(-W/N), W(d,11) = 1 + d sum_{i=1..5} (d-1)^(2i-1)); then search with ORBIT and AFROB=1, and compare start
costs (RANDORB=10) with plain conjugation alpha on the same group. If no cell fits, say which D = 9/10 cell it would fit.
Command: `ORBIT="3 m f" AFROB=1 THREADS=1 timeout 105 nice -n 10 $B/haar_sym d 11 100 <seed> 4 OUT sl q n`.
Scorer: haarcheck_gen (N <= 3e7) or build_haar2.py (2N <= 2M). Cap 180 MB. Folder: research/squads/beyond11b/r1/g05/.
