# a01: (4,9) with odd-order and Frobenius groups (beat the 2013 table value 4,970 = 2 x 2,485)
Goal: a 4-regular Haar graph of diameter 9 on 2N >= 4,972 vertices (N = |G| >= 2,486). Never beaten since 2013.
mu at N = 2,486 is 47 (W = 9,841): far above where random S works, so you need a group whose words spread better than
random. Odd-order Frobenius groups did that at (4,11) (mu 44, research/frontier/beyond11/FROBENIUS.md).
Groups (N in 2,486..2,600): the only odd Frobenius Z_p x| Z_k with good k is Z101 x|_5 Z25 (N 2,525, mu 51); k = 3 ones
(Z829 x| Z3 2,487, Z853 x| Z3) collapse. So also try: other odd-order groups of order 2,487-2,560 that groups.py or
haar_gen3 can build: Z_m x|_r Z_k with m composite and k odd (e.g. order 2,489 = 19 x 131? check), products of two
Frobenius groups (Z7 x| Z3) x (Z_q x| Z_l), Z_p^2 x| Z_k ("semi" in groups.py), heis, and EVEN-order non-metacyclic
groups NOT in the earlier sweep (SL(2,q) x small, agl1 q x Z_n, dicyclic). Earlier sweep: 1,538 groups, mostly
metacyclic, cost 10-18 after 300 s.
Search: plain random S with `$B/haar_gen3s 4 9 100 <seed> 8 OUT <spec> 1` (SAVEBEST=b.txt), many seeds; finish
cost-2 states with haar_gen3t TFULL=1 TARGP=100. Since N is tiny, an exhaustive or near-exhaustive search over S up to
group automorphisms is possible: consider writing a small C program that tries all S = {e,a,b,c} with a fixed up to
Aut(G) for Z101 x| Z25 (N^3/|Aut| sets; each check is a BFS of 5,050 vertices).
Scorer: build_haar2.py on the solution file (or apsp on an edge list). Folder r1/a01/.
