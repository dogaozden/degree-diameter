# a02: (3,9) exhaustive cubic Haar sweep over ALL small groups of order 254-330 (beat the 2013 table value 506)
Goal: a cubic Haar graph of diameter 9 on 2N >= 508 vertices (N >= 254). Never beaten since 2013 (Moore bound 1,022).
Why it might work: at D = 11 and 12 the exhaustive pair search over every metacyclic group (Z_m x|_r Z_k, ANY m, k,
r) found (3,11) 1,474 at mu 46 and (3,12) 2,176, far beyond annealing. At (3,9) the current value is at mu 33.6 and
the earlier attempt was only haar_gen3 ANNEALING on N = 254-275 (best cost 30). A cubic Haar graph has S = {e,a,b},
so all N^2/2 pairs can be tried per group in well under a second.
Plan: use `$B/exh3 TABLE.bin 9 OUT` with tables from groups.py (grammar in its header), driven like
research/squads/beyond11b/tools/sweep_meta.py (copy it, change D and the order range). Sweep EVERY metacyclic
Z_m x|_r Z_k with N = m k in 254..330 (all m, k, all r of order k up to the obvious equivalences), then the other
families groups.py builds (dih, semi Z_p^2 x| Z_k, agl1, heis, sl2/psl2/pgl2 small, products "A x B"). Record the best
cost per group in a table file (sorted). Start at N = 254 and go up; the smallest N that solves is enough to beat 506,
but report the largest N solved.
Also report the smallest cost found at each N even if nonzero (it tells whether Haar graphs can reach (3,9) at all).
Scorer: build_haar2.py on the solution file, or apsp. Folder r1/a02/. Memory: tables are N^2 x 2 bytes (tiny).
