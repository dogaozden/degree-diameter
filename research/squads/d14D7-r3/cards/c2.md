# r3 c2: fixed-size tabu search (k-coloring style)
For a target size k (start at 156), search for a k-subset of vertices with no edges: state = k vertices, cost =
number of edges inside, moves = swap one inside vertex for an outside vertex (choose the swap reducing cost most,
tabu tenure on recently moved vertices, aspiration), incremental "inside-degree" counts. When cost reaches 0, save and
increase k. Runs up to 600 s via heavy.sh. Score: best VALID N.
