# d03: endgame code: let the search move the fixed generators
haar_big0 draws the f-1 alpha-fixed generators once and never moves them, while the last holes of near misses are
alpha-fixed elements (round 1). Copy research/frontier/beyond11/haar_big0.c to your folder as haar_fx.c and add env
FXMOVE=q: with probability q/100 a step replaces one random fixed generator (slot 1..f-1) by a random alpha-fixed element
(not e, not already in S; the candidate list is built in main, see 'cand' near 'fixed generators') and evaluates it with
the same accept rule; K candidates per step as for orbits. Build: gcc -O3 -march=native -fopenmp -o haar_fx haar_fx.c -lm.
Test 1 (cheap): (11,9), groups from pick.py 11 9 12 15 3 60, "3 3 2": FXMOVE=0 versus FXMOVE=30, 2 seeds x 60 s each.
Test 2: start from research/squads/beyond11/r1/c01/out443.sol.best ((11,11), SL(2,443) x Z7, cost 2) with FXMOVE=30.
Any (11,9) solution must pass haarcheck_gen. Memory cap 0.6 GB. Folder: research/squads/beyond11/r2/d03/.
