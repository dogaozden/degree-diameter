# c6: symmetric matchings (Singer cycle of SL(3,q) inside G2(q))
In Tits coordinates (data/gh_q_coords.txt) the maps x -> (A x_W, x3, A^{-T} x_{W*}) with A in SL(3,q),
x_W = (x0,x1,x2), x_{W*} = (x4,x5,x6), are automorphisms of H(q). A Singer cycle (an element of order q^2+q+1 in SL(3,q),
e.g. multiplication by a norm-1 generator of GF(q^3)^* written as a 3x3 matrix) acts semiregularly on points and lines.
Task: (1) build the permutation of points (and hence lines) induced by a Singer element for q = 5 (order 31) and q = 7
(order 57); verify it maps lines to lines; (2) generate random EQUIVARIANT matchings (sigma(h p) = h sigma(p)) and write
them as glift INIT state files (format in glift.c: header, then per point "sigma_1 h_1 sigma_2 h_2", then per flag
voltage); (3) compare random equivariant vs random plain matchings for GH(5)+2 over Z6 (HT "1 4") with EVAL=1;
(4) if time permits, write an orbit-level annealer (a move changes sigma on a whole orbit) and run it on GH(5)+2 Z6.
Score: lowest full cost reached for GH(5)+2 over Z6 with equivariant matchings (unit "misses"; 0 would be a new (8,7)
record, 46,872 vertices).
Compute: at most 6 heavy runs of <= 300 s.
