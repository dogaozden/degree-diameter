# c12: counting bounds for extra copies (theory with measurements)
For the lift of GH(q)+j matchings over Z_m with polygon voltages 0 and hop voltages h_1..h_j, a target in copy g is
reachable within the same-colour budget 6 only by walks whose hop voltages sum to g. Copies 0, +-h_t are always covered
(DGQ). For the other elements, list the walk patterns (directions point->line / line->point, GH segment lengths)
with total length <= 6 and compute the maximum number of points each pattern can reach from a point source, as a
function of q (exact formulas, e.g. (q+1)^2(q^2+1) for some patterns; use GH(q) BFS on q = 3, 5, 7 to confirm).
Then give, for each (q, j, m, HT), the necessary condition sum(pattern sizes for element g) >= |P| = (q^6-1)/(q-1)
for every non-DGQ element g, and tabulate which (q,j,m) pass at Delta = q+1+j = 14 (q = 11 j=2 m>=6; q = 9 j=4 m>=14;
q = 8 j = 5 m >= 24; q = 7 j = 6 m >= 46) and at other Delta (5..16). Include 3-hop patterns. Note where the bound
is tight. Write bounds.md.
Score: number of (q,j,m) cases at Delta = 14 that beat 1,771,560 AND pass the counting condition (unit "cases").
Compute: light (Python BFS on small GH); at most 3 heavy runs of <= 300 s.
