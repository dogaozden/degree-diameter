# c02 — hubs on the (16,5) graph, using its symmetry
Same hub rules as c01 (read them there: research/squads/beyond-small/r1/c01.md). Your twist: the controller is a Z22
lift, so g → g+1 (on both a_i and b_j controller coordinates, fibre fixed) is an automorphism of G. Find ONE hub set
N (≤ 17 B-vertices) whose distance-≤3 balls cover side A AND whose 22 translates N+t are pairwise disjoint; then the
22 hubs h_t with N(h_t) = N + t come for free for condition (1). Check condition (2) among them (same-side hubs need a
pair at distance ≤ 2) — choose N so that N and N+t contain a pair at distance ≤ 2 for every t. Stack several such
orbits (disjoint), both sides. Also look for further automorphisms of G (e.g. fibre maps x → x + c_u that commute with
the chart) to get bigger orbits. Report the largest apsp-VALID n.
Time box: 40 min. Folder: research/squads/beyond-small/r1/c02/.
