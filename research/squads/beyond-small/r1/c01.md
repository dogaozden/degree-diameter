# c01 — hubs on the (16,5) graph, greedy set cover
Every vertex of the 33,792 graph G has one spare degree (16 < 17). Add new vertices ("hubs"). A hub h on side A joined
to a set N of ≤ 17 B-vertices (each B-vertex used by at most one hub) keeps diameter 5 iff
 (1) every A-vertex is within distance 3 of N (then h reaches all of A in ≤ 4; h reaches all of B in ≤ 5 automatically,
     since B–B distances in G are ≤ 4),
 (2) hub–hub pairs: two A-hubs need some b ∈ N(h), b' ∈ N(h') at distance ≤ 2; an A-hub and a B-hub need some
     b ∈ N(h_A), a ∈ N(h_B) at distance ≤ 3 (or a direct hub–hub edge).
Old pairs only get closer. Task: compute, for every B-vertex, its distance-≤3 A-ball as a bitset (16,896 bits), then
greedy set cover to find one N of size ≤ 17 covering A → first hub (n = 33,793, check with apsp!). Then grow: many hubs
with pairwise disjoint N's, then fix hub–hub conditions (or add hub–hub edges, which use hub degree). Do both sides.
Report the largest checked n. Upper limit ≈ 33,792 + 2·993.
Time box: 40 min. Folder: research/squads/beyond-small/r1/c01/.
