# c09 — test the director's Z8 obstruction (theory check, small q)
Header item: the director argues that a Z8 lift of W(q) + one doubled matching (voltages 1, 5) + one plain matching
(voltage 2), flags carrying 4ν (ν ∈ {0,1}), has diameter 5 only if ν(geod σ(p)→u) = ν(geod p→σ(u)) for almost all
point pairs (p,u) (and line pairs), and that this conflicts with the opposite-pair parity condition unless σ is a
polarity of W(q) and ν is σ-invariant. Test it: (a) W(8) has a polarity (q = 2^3): build W(8) (research/d10D7/gqgen.c
gives gq_q8.bin; or build it yourself), find a polarity σ (an incidence-preserving point↔line map with σ² = 1), take a
random σ-invariant ν, build the Z8 lift (Δ = 9+3 = 12, 8·1,170 = 9,360 vertices) and check diameter with apsp (d=12).
If needed anneal σ-invariant ν with apsp-based cost. (b) Same lift for W(7) or W(9) with a random bijection σ: report the
minimum far-pair count you reach. Report what happened; score = n if (a) is VALID (note: 9,360 is below the (12,5) value
9,840, so this is a theory test, not a record).
Time box: 40 min. Folder: research/squads/beyond-small/r1/c09/.
