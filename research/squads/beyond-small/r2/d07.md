# d07 — structured hub families from a new controller vertex
Instead of independent hubs, add a whole new A-controller vertex u* with fibre F4^4: vertex (u*, x) is joined to lines
(v_i, M_i x + F4 c_i) in a few B-controller vertices v_i (only for x in a subset X_i where x → line is injective, so every
old vertex is used once). Choose v_i, M_i, c_i, X_i so that every (u*, x) covers A (4 lines) and pairs (u*, x), (u*, x')
are compatible by algebra (same-fibre distance-2 differences are the 4 lines F4 b_t of the chart). Count how many
(u*, x) you can add with guaranteed compatibility, then combine with other hubs. Report the best valid graph.
Time box 40 min. Folder r2/d07/.
