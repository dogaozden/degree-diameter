# d01 — adaptive hub growth, side A
Start from the 191 A-hubs (r2/hubsA_191.txt). Grow the packing one hub at a time, but build each new hub with a JOINT
greedy: choose 4 unused, disjoint lines (any direction, any controller vertex) whose distance-3 balls cover A AND whose
16 vertices hit R(h) = (distance-≤2 set of N(h)) for every current hub h. Score lines by (new A-coverage) + (number of
not-yet-hit R(h)'s they hit), with randomization and restarts; allow a 17th vertex to finish the hitting/cover. Also
try removing a hub that blocks many candidates and re-growing (local search). Report the largest valid A-hub count
(merge with director/merge_hubs.py, check with apsp). Time box 40 min. Folder r2/d01/.
