# d03 — strong max-clique search on the hub compatibility graph
hubpack.c's clique search is crude (greedy + 1-swaps). Copy hubpack.c, make it dump the candidates and the compatibility
graph (DIMACS edge format or a bitset file), and run a strong max-clique heuristic on 10,000–20,000 candidates: e.g.
tabu search (MN/TS), dynamic local search (DLS-MC), or iterated greedy with plateau moves and restarts, all in C.
Compare with hubpack's number on the same candidates. Report the best packing (side A, then side B if time) as a
valid graph. Time box 40 min. Folder r2/d03/.
