# e01 — adaptive orbit growth, side A
adaptive orbit growth, side A. Start from the 27 A-orbits. Generate new key-disjoint 4-line covers N (keys not used by the current orbits) that are compatible with every hub of the current packing (N vs O+u for all orbits O and all u) and self-compatible (N vs N+u, u ≠ 0), with a joint greedy as in r2/d01/grow.c (score lines by cover gain + number of not-yet-met hubs they meet). Add orbits one by one; restart/backtrack when stuck. Report the largest valid graph (A-orbits + the 21 B-orbits).
Time box 40 min. Folder r3/e01/.
