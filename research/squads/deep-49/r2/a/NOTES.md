## Groups (GAP scripts: mkfib.g, mkA5C7S3c.g; exporter export_r2a.g, exportpc_r2a.g; tables in g/)
- S5 x_C2 X = {(s,x) : sign(s) = chi(x)} in S5 x X, |X| = 42, chi onto C2 with kernel K (K = unique index-2 subgroup).
  Built as the subgroup generated by A5 x K and (transposition, x1), x1 not in K. Checked: size 2520.
  - X = D21 (DihedralGroup(42)): AbelianInvariants [2], 57 classes.
  - X = C7:C6 (SmallGroup(42,1)): [2,3], 26 classes.
  - X = C3 x D7: [2,3], 66 classes.
  - X = C7 x S3 (extra, not in the card): [2,7], 84 classes.
  - Class counts separate them from the direct products A5 x X (X = C7:C6, D21, C3 x D7, C7 x S3: 30, 60, 75, 105 classes)
    and from S5 x F21 (35 classes); the fibred groups have 26, 57, 66, 84. Not a full isomorphism test.
- A5 x (C7 x S3) (extra, direct): 105 classes. GAP AutomorphismGroup failed on this perm group (MovedPoints), so the
  Aut generators were written by hand: Aut(A5) x 1 and 1 x Aut(C7 x S3) (7 generators; hx sanity-checks them).
- Completeness argument for the non-solvable groups of order 2520 (not checked by computer): the solvable radical R and
  G/R force one of A7, A6 x C7, PSL(2,7) x C15, PSL(2,8) x C5, A5 x X (6 X), S5 x_C2 X (6 X, two of them are S5 x C21 and
  S5 x F21), SL(2,5) x C21, SL(2,5) x F21. The r1 list covers all but S5-type C7xS3 and A5 x C7xS3.

  .aut generators), so requiring them covered keeps the hx reduction exact.
