## Classical Moore bipartite values for D = 3 (cross-check, not a new find)
The bipartite Moore graph of diameter 3 is the incidence graph of a projective plane of order q = Δ−1 (order 2(q²+q+1)).
Projective planes exist for q = 16, 17, 19, so the values 546 (Δ=17), 614 (Δ=18) and 762 (Δ=20) are classical
published values. Reference: incidence-graph view in 1203.3588 (the Moore bound M^b(d,3) is the target). The search
summary stated the projective-plane correspondence, but I did not read a page that gives the exact numbers in full, so
treat this as background. These agree with HEADER.md. Δ=19 (624) is not Moore; no published value was found for it.
