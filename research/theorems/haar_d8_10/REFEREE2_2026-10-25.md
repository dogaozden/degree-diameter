## Checks of the new and rewritten text

**Corollary 4.2 (L442–458): correct.** I checked each step:
- Pigeonhole gives distinct values for the W binding A-words, including the empty word at odd D.
- Two arcs of a 2c-cycle give distinct reduced words with equal values, and their last letters differ, since the edges at a vertex carry distinct letters.
- The parity case uses c ≤ D − 1. The other case appends a letter t, which exists because Δ ≥ 3, and gives length c + 1 ≤ D − 1.

Two standard facts are stated without a reason:
- girth ≤ 2·diam for a bipartite graph with a cycle (a shortest cycle longer than that has a chord-path shortcut);
- girth 2D ⇒ diam ≥ D (antipodes on a shortest cycle).

One clause each would make the proof self-contained. Minor.

**Proposition 3.3(a)–(b) (L313–331): correct.** The order |G|·ord(α), the isomorphism h ↦ ρ_{h⁻¹}, α ↦ α̂, and the distance-preservation proof of (b) all hold. ℓ now means a radius; it is no longer used elsewhere, so there is no clash.

**Proposition 3.4(a) (L343–346, L356): correct.** v*(S) = β(v(S))⁻¹ holds for any β with β(S) = S. v** = v and the last clause need β² = id, as stated.

**"What this means for the search" (L365–376): correct.**
- Block replacement: if w′ is reduced it is a binding word; otherwise its value is that of a shorter reduced word of the same parity.
- Norm relation: u⁻¹ = α(u)⋯α^{k−1}(u) is the value of the concatenation σ^{k−1}v, …, σv in reading order, all with the same sign pattern since each block has even length.

One residual imprecision (minor), at L369–370: "for conjugation in SL(2, q) × Z_n that is a fraction of order 1/q". The lower bound is 1/|Fix(β)|. That is of order 1/q only when the Z_n-part of Fix(β) is bounded. For pure conjugation (r = 1) it is 1/((q ± 1)n).

**§2.6, "What no checker uses" (L243–248): correct.** α(Ss₀⁻¹)·α(s₀)s₀⁻¹ = Ss₀⁻¹, and c ∈ T. The exhaustive claim matches orbit_check.py and orbit_check2.py, both of which try c = e first.

**§3.5, "What does not change" (L410–415): partly fixed. Minor, heuristic section.**
- With e ∈ S, the other fixed generators come from Fix(α) \ {e}, so the binomial is C(|Fix| − 1, f − 1), not C(|Fix|, f − 1).
- At f = 0 the displayed formula gives 0. The count meant is (N/k)^m/m! α-closed sets, which give about Δ·(N/k)^m/m! translates containing e. Say that.
- "Agree up to … the |Fix| term" holds only if that term, k(f − 1)·ln|Fix|, is about (f − 1)·ln N, i.e. when |Fix|^k ≈ N. Say so, or just say they differ by (f − 1)·ln N + O(factorials).

**Remark after Theorem 4.3 (L477–478): correct.** It agrees with the computed values for Δ ≤ 6.

**Remark after Corollary 4.4 (L502–508): correct.**

**§4.4, the lift family (L527–537): correct as now stated.** I checked the source proof:
- every voltage in S(T) is realised by a point→line walk of length ≤ 2c + 1 (k = l is needed for 2t_k);
- line→point uses −S(T) = Z_M;
- same-colour pairs need one more base step.

Brute force on bases C_8, C_12, C_16, K_{3,3} and GQ(2,2) with T ∈ {{1} mod 3, {1} mod 4, {1, 2} mod 5, {1, 4} mod 10, {1, 4, 7} mod 16} and random bijections: 100 lifts, none above 2c + 2. Minor: P and L name the colour classes, and L also means a word length elsewhere.

**"Geometric reading" (L86–91): correct.**
- Lines are incident with S⁻¹h.
- At D = 3 with |G| = Δ² − Δ + 1, S⁻¹S = G holds iff every non-identity element is s⁻¹t for a unique pair (s, t), by counting.
- Theorem 2.4(b) also needs SS⁻¹ = G. That follows because the dual of a projective plane is a projective plane, but the note does not say so; add half a sentence. Brute force agrees: in Z_7, Z_13, Z_21 and the nonabelian Z_7 ⋊ Z_3, the two conditions select the same sets (14, 52, 42 and 294 sets).
- The Fano example and equality in Theorem 4.1 (7 = W(3, 3)) are right.
