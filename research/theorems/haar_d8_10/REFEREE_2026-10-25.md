## Findings

1. **L50 (summary table, Prop. 3.4). Error (overclaim).** The table says "forces word coincidences on at least |G|/|Fix| elements; odd order avoids this". Prop. 3.4 proves less:
   - |Anti(β)| ≥ |G|/|Fix(β)|;
   - an even block whose value lies in Anti(β) has a partner block with the same value.

   Nothing shows that any binding word contains such a block, so "coincidences on ≥ |G|/|Fix| elements" is not proved. Odd order does not avoid coincidences either: (b) still gives norm relations, as L352–353 says.
   *Fix:* "an involution β gives |Fix(β)|·|Anti(β)| ≥ |G|, and even blocks with value in Anti(β) pair up; for odd order, Anti(α) consists of the elements of order ≤ 2 in Fix(α)."

2. **L53, L439. Error.** For Δ ≥ 3, A(Δ, D) is not a polynomial in D. It is a quasi-polynomial of period 2: one polynomial of degree Δ − 1 on even D and a different one on odd D, with the same leading term.
   - Example: A(3, D) = 3D²/4 for D even and (3D² + 1)/4 for D odd. This gives 48, 61, 75 at D = 8, 9, 10.
   - No single quadratic fits A(3, 2..5) = 3, 7, 12, 19.
   - I checked Δ = 3–6 for D up to 17 (t_A.py).

   *Fix:* "Θ(D^{Δ−1}); a polynomial of degree Δ − 1 in D on each parity class of D."

4. **L316–318. Gap (heuristic stated as fact).**
   - "Does not make any element more likely to be covered" is a probabilistic claim, and §3.3 has no probability model.
   - The word "So" presents it as a consequence of Prop. 3.3, which says nothing about probabilities.
   - Under the §3.5 model, fixed points are *less* likely to be covered (miss rate e^{−λ/k}).

   - "Does not reduce the number of binding words" is true only because W(Δ, D) counts letter sequences and does not depend on S.

   *Fix:* "W does not depend on S; by Prop. 3.3, coverage is constant on ⟨α⟩-orbits." Move everything about likelihood to §3.5.

5. **L348–350. Gap.** Replacing a block v by v* inside a reduced binding word w gives a word w′ with the same value. But w′ need not be reduced at the two block boundaries, so it need not be a binding word.
   - Example: G = Z_7, S = {1, 2, 5, 6}, β = inversion, so Anti(β) = G.
   - w = (1, 2, 6) is reduced, with A-value 6 − 2 + 1 = 5.
   - The block (2, 6) sits in positions 2–3. It is evaluated as a B-word and becomes v* = (1, 5).
   - w′ = (1, 1, 5) has value 5 and is not reduced.

   The text should also say that the block is evaluated with the sign pattern of its position: an A-pattern if it starts at an odd position, a B-pattern if it starts at an even one.
   *Fix:* "w has the same value as w′. If w′ is not reduced, that value is also the value of a shorter reduced word."

6. **L415–420 (Cor. 4.2). Gap.** The step "equality ⇒ girth 2D, hence the incidence graph of a generalized D-gon" is neither proved nor cited. A short proof:
   - Equality |G| = W forces the reduced A-words of the binding parity and length ≤ D − 1 to have pairwise distinct values.
   - A cycle of length 2c < 2D through (e, A) (every cycle meets an A-vertex; translate by some ρ_h) gives two distinct reduced walks of length c to its antipode.
   - If c has the binding parity, this contradicts distinctness. Otherwise append one letter different from both last letters (possible since Δ ≥ 3); this gives two distinct reduced words of length c + 1 ≤ D − 1 with equal value.
   - So the girth is at least 2D. With diameter ≤ D this forces girth 2D and diameter D, which is Tits' definition.

   Alternatively cite Singleton (1966). The Feit–Higman citation and the octagon argument (2s² is never a square) are correct.
