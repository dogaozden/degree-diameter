## How: self-dual connection sets

The 1,200 record's S (SL(2,5) x C5) is **self-dual**: some automorphism beta of G inverts every element of S, and
another one gives psi(x) = beta(x)^-1 with psi(S) = S and orbits {e} + three pairs (`src/sdcheck.c`, all 480
automorphisms). If psi(S) = S for psi(x) = beta(x)^-1, then (g,A) -> (beta(g),B), (g,B) -> (beta(g),A) is an
automorphism of H(G,S) that swaps the colour classes, so X X = G (side A within distance 4) already implies
Y Y = G (side B). Only half of the diameter test has to pass, which makes solutions far more common: on
SL(2,5) x C5 the self-dual family has 26 solutions against 4 for plain automorphism-invariant sets.

`haar75 anti` enumerates, for beta = identity and for every class of involutory automorphisms, every S that is a
union of psi-orbits (sizes 1 and 2) with the identity among the psi-fixed elements (no loss: if s0 in S is
psi-fixed, s0^-1 S is invariant under the psi' of beta' = conj(s0^-1) beta, again an involution), types
(fixed, pairs) = (1,3), (3,2), (5,1), (7,0). Type (7,0) means S is inside {x : beta(x) = x^-1}, i.e. H(G,S) is a
Cayley graph of G : <beta> generated by 7 involutions. All hits so far are of type (3,2).

Equivalently, this family is exactly the set of 7-valent **bipartite Cayley graphs** Cay(Ĝ, T) (T = T^-1 outside an
index-2 subgroup G of Ĝ): T has odd size, so it contains an involution t0; then Ĝ = G : <t0>, and with
beta = conjugation by t0 and S = t0 T (which contains e) we get psi(S) = S. The types (f, m) count the involutions f
and the inverse pairs m of T. So `haar75 anti` over all involutory automorphism classes of every group G of order n
searches every 7-valent bipartite Cayley graph on 2n vertices (complete except for CAPPED types).
